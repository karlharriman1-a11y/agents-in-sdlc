**[GitHub Copilot CLI][about-copilot-cli]** は、エージェント型コーディングアシスタントとして GitHub Copilot をターミナルに導入します。コードベースを調査し、コードを生成し、コマンドを実行して、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業に集中できます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを把握します。
2. 星評価の小さな変更を加え、ブラウザーでレビューし、最初のプルリクエスト (PR) を手動でマージします。
3. フィルタリング issue から始め、Plan モードで方針を定め、Autopilot モードで構築して、Interactive モードでレビューします。
4. リポジトリのインストラクションを更新し、フィルタリング作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルタリングを確認します。
7. 品質保証 (QA) カスタムエージェントを作成し、要件、カバレッジ、検証の根拠をレビューします。
8. フィルタリングの変更全体をレビューし、フィルタリング PR に Agent Merge を使います。
9. コンテキスト、モデル、共有、cloud agent への任意の委任に便利なスラッシュコマンドを確認します。

ワークショップに集中できるよう、PR は2つ作成します。1つ目は星評価、2つ目はインストラクションの更新、スキルの更新、QA プロファイル、テストを含むフィルタリング機能です。各ツールの学習を通して作業を積み上げられるよう、フィルタリングと品質ワークフローは1つの会話とブランチで進めます。

## 前提条件

このワークショップに参加する前に、次の条件を満たしていることを確認してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、または Enterprise** プランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランをお持ちでない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
