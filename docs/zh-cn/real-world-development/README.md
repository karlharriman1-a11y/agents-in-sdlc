通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代式地规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为以开发者为主题的棋盘游戏提供众筹服务。团队已将待办工作记录为 GitHub issue，供你接手。其中既有筛选和分页等功能，也有无障碍访问和编码规范等质量改进。

## 选择开发环境

无论你使用哪种环境，都可以使用 GitHub Copilot。选择适合自己的开发方式。每个工作坊都会从各自的环境设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright 模型上下文协议 (MCP)、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

运行并行代理会话、切换会话模式、在画布中协作，并在桌面应用中管理 GitHub issue 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步代理、引导其工作、监视进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
